# comeback.mjg — Desktop Focus & Urge Shield (Companion Browser Extension)

This lightweight Manifest V3 browser extension pairs with your **comeback.mjg** personal operating system to block compulsive digital habits and redirect distraction tabs directly into your active focus session or physiological urge breaker.

---

## 🚀 How to Install in Chrome / Brave / Edge (30 Seconds)

1. Open your browser and navigate to the Extensions page:
   - **Chrome**: `chrome://extensions`
   - **Brave**: `brave://extensions`
   - **Edge**: `edge://extensions`
2. Enable **Developer mode** (toggle switch in the top-right corner).
3. Click the **"Load unpacked"** button in the top-left corner.
4. Select this directory:
   ```
   d:\new projects\habit-tracker\companion-extension
   ```
5. Pin the extension to your browser toolbar!

---

## ⚡ Features
- **Dynamic Declarative Redirection**: When you turn on Focus Shield, visits to YouTube, Instagram, X (Twitter), Reddit, TikTok, Facebook, etc., are instantly redirected to:
  `https://ptos-exec-89214.web.app/focus?blocked=true`
- **Custom Blacklist Editor**: Add or remove any specific domain in real time.
- **Focus Timer Presets**: 25m Sprint, 45m Block, or 90m Deep Work with automatic badge updates.
- **Light Theme Design**: Pure clean light theme matching the comeback.mjg design system.
